Interaction Language

One vocabulary across the product. Tab through this page to see the focus ring; hover the cards, chips, and rows above.

StateTreatmentTiming
HoverValue shift only — fill darkens a step, border firms, cards gain state shadow. Never translate or scale.120ms
Focus-visibleVermilion border/outline + 3px vermilion-tint ring, identical on every control.—
Active / pressscale(0.97) — the only transform in the system.120ms
Open / revealDropdowns & card state, ease-enter, origin-aware.200ms
Toast / revealBlur-in enter, auto-dismiss, reduced-motion collapses durations to ~0.320ms
Dialog contractDrawers/sheets/palettes: role="dialog", Tab trapped, Escape closes, focus returns to trigger, scroll locked.—
Toggle contractSave star, mark-applied: aria-pressed synced with visual state.—
Pending contractaria-busy="true" dims + blocks re-press, keeps focus; buttons are never disabled mid-flight.—
Error contractaria-invalid → gold border/ring; message linked via aria-describedby. Gold flags, vermilion never panics.—
Touch contractCoarse pointers: every tap control clears ~44px; active tab/nav links carry aria-current="page".—
